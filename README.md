## Overview
This project examines U.S. border crossing data obtained from the U.S. Customs and Border Protection (CBP) portal to identify trends and patterns in cross-border movement. 
The analysis focuses on transforming raw data into clear, interpretable visual insights.

## Data Source
Public border crossing data from the U.S. CBP portal
Only publicly available data is used

## Methods & Tools
Language: R
Libraries: ggplot2, dplyr, tidyr, RColorBrewer, ggmap
Techniques: Data cleaning and transformation, Exploratory data analysis, Advanced data visualization

# Output
A data storytelling pdf poster summarizing key findings
